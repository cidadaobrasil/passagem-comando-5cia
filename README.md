# Passagem de Comando — 5ª Cia PM

Relatório de passagem de comando da 5ª Cia PM, preparado para a substituição do Cap PM Josemar pelo Ten PM Rodrigo.

**Período da substituição: 17/08/2026 a 22/01/2027.** O `index.html` é a versão vigente; não manter anexos gerados com datas antigas.

## Como é

Site estático de página única (`index.html`). Sem build.

## Como publicar

Editar o `index.html`, commitar e dar push na `main`.

## Estrutura

Cinco seções, conforme o texto reformulado do arquivo Word `Passagem_de_Comando_5aCiaPM (3).docx`:

1. Pendências e pontos de atenção
2. Rotinas e controles
3. Temas operacionais
4. Agenda do período
5. Referências internas

O índice da barra lateral e o do menu mobile são gerados por JS a partir das seções. Para adicionar uma seção, basta criar o `<details class="report-section" id="sN">`; o índice se atualiza sozinho.

## Estado

Documento de uso interno, atualizado em 11/08/2026, com responsabilidade territorial sobre Guararapes, Valparaíso, Bento de Abreu e Rubiácea.
